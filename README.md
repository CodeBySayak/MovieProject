# MovieVerseBySayak 🎬

MovieVerseBySayak is a full-stack movie web application where users can explore movies, view AI-generated summaries, rate films, add reviews, and discover trending movies based on community ratings.

🌐 Live Demo:  
https://movieversebysayak.onrender.com/

---

## Features

- Browse and explore movie collection
- Add new movies with posters, descriptions, and release year
- Edit and delete movie entries
- Search movies by title or description
- AI-generated movie summaries using Gemini API
- Movie ratings and review system
- Trending movies section based on ratings
- Responsive UI with Bootstrap
- MongoDB database integration
- Full CRUD functionality
- Dynamic EJS templating
- Online deployment using Render

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Gemini API
- Render

---

## Installation

Clone the repository:

```bash
git clone https://github.com/CodeBySayak/MovieProject.git
```

Move into project folder:

```bash
cd MovieProject
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
node app.js
```

Open in browser:

```text
http://localhost:3000
```

---

## Environment Variables

Create a `.env` file in the root directory and add:

```env
apiKey=YOUR_GEMINI_API_KEY
MONGO_URL=YOUR_MONGODB_CONNECTION_URL
```
